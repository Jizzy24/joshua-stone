# Saffron & Stone website

Responsive demo website files:
- `index.html` — page content
- `style.css` — layout and styling
- `script.js` — mobile menu and demo enquiry interactions

## Before publishing
1. Replace the sample brand name, menu items, descriptions and prices in `index.html`.
2. In `script.js`, replace the empty `phone` value with your WhatsApp number, including country code and without `+` (for example `2348012345678`).
3. Add your real address, opening hours, social links and payment/order process.
4. The contact form is a front-end demo. Connect it to WhatsApp or a form backend before taking real customer enquiries.

Open `index.html` in a browser to preview. No build tools are required.
